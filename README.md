# 回忆展开 · pico-memory-gallery

> PICO Space Program 2026 参赛作品
> 赛道：**Spatial 空间应用创作 - Android Kotlin Compose**
>
> 仓库：<https://github.com/Sghosting/pico-memory-gallery>

## 一句话

双掌一拍，在真实房间里展开一条照片领域；走近照片可拉开放大为全景，AI 讲述每张照片的故事，一键生成分享卡发给家人。
